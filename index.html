🔥 Bienvenue à la Formation

Apprends à créer ton site web de A à Z. Cette formation est gratuite et te guidera étape par étape :

  • Comment Créer un site complet
  • Comment Mettre ton site web en ligne
  • Comment Gagner de l'argent avec ton site

📘 Module 1 : HTML

HTML permet de créer la structure du site web.

<h1>Bienvenue</h1>
<p>Mon site web</p>
<a href=\"#\">Clique ici</a>

Avec HTML tu peux créer :

  • Titres
  • Paragraphes
  • Boutons et liens
  • Images

🎨 Module 2 : CSS

CSS rend ton site beau et stylé.

body {
 background: blue;
 color: white;
}

Avec CSS tu peux :

  • Ajouter des couleurs
  • Modifier les polices et tailles
  • Créer des mises en page modernes
  • Rendre ton site responsive

⚙️ Module 3 : JavaScript

JavaScript ajoute de l’interactivité sur ton site.

alert("Bienvenue sur mon site !");

Avec JavaScript tu peux :

  • Réagir aux clics
  • Créer des animations
  • Afficher des messages dynamiques
